# micamall

Bilingual premium slider collection for **MikaMall Kish** built with **raw HTML, CSS, and JavaScript**.

## About

This repository contains independent, reusable slider projects designed for luxury and retail product showcases with **FA/EN language support**.

## Features

- Pure HTML, CSS, JavaScript (no framework)
- RTL/LTR bilingual structure (Persian/English)
- Responsive layout for mobile and desktop
- Clean folder-based architecture
- Easy customization for product campaigns
